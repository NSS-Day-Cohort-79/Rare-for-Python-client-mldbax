# Rare: The Publishing Platform for the Discerning Writer

## About
Rare is a full-stack publishing platform where users can create and manage posts, organize content by categories and tags, and explore writing from other authors.

---

## Features
- User registration, login, and logout
- Create, edit, and delete posts
- Manage categories
- Manage tags
- Browse posts by other authors

## Getting Started
1. Clone the [client repository](https://github.com/NSS-Day-Cohort-79/Rare-for-Python-client-mldbax)
    1. Install dependencies: `npm install`
    1.  Run the code `npm start`
    1.  Visit http://localhost:3000 in your browser

2. Clone the [api repository](https://github.com/NSS-Day-Cohort-79/Rare-for-Python-api-mldbax)
    1. Make sure server is running

3. With the server also running, check that the login, register, and logout functionality is working.
4. This template is using [Bulma](https://bulma.io/documentation) for styling. Take a little bit of time to familiarize yourself with the framework if you would like to continue using it.
